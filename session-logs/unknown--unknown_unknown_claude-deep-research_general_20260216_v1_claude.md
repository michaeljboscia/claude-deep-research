## Key Decisions
1.  **Architecture Shift: `connectOverCDP` vs `launchPersistentContext`**:
    *   **Decision:** We abandoned Playwright's native browser launching (`launchPersistentContext`) in favor of connecting to an existing Chrome process via CDP (`connectOverCDP`).
    *   **Why:** Cloudflare Turnstile aggressively fingerprints headless browsers and even headed browsers spawned directly by automation libraries (detecting the CDP handshake). By spawning a standard Chrome process via shell and attaching Playwright to its remote debugging port, we completely bypassed Cloudflare detection.
2.  **Input Method**:
    *   **Decision:** Used `keyboard.type()` instead of `.fill()`.
    *   **Why:** Claude's input is a ProseMirror `contenteditable` div. It relies on key events to trigger state changes; direct value injection often fails or doesn't trigger the "send" button activation.
3.  **Process Lifecycle**:
    *   **Decision:** Removed `browser.close()` and `killChrome()` from the final cleanup steps.
    *   **Why:** Deep Research takes time. Closing the browser immediately after submission kills the research process. The browser must remain open.
4.  **UI Interaction Strategy**:
    *   **Decision:** "Research" is not a standalone button. Logic updated to click `aria-label="Toggle menu"` (+) -> wait for `role="menu"` -> click "Research" menu item.
